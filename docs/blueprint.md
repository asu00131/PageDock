# **App Name**: PageDock

## Core Features:

- Link Grid: Allow users to add a grid of links to other web pages.
- Link Customization: Allow users to customize the links on the page.
- Local Storage: Allow users to save their link configuration in the browser's local storage, so they can reload their links even after closing the browser.

## Style Guidelines:

- Primary color: Neutral gray (#F0F0F0) for a clean background.
- Secondary color: Light blue (#E0F7FA) for link backgrounds.
- Accent: Teal (#009688) for highlights and interactive elements.
- Grid-based layout for easy arrangement of links.
- Simple, monochrome icons for link representation.
